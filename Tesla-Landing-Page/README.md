# Tesla Landing Page Clone (Themba Dev Cars)

A responsive, Tesla-inspired landing page built as part of the Full Stack AI Engineering course at Zaio Academy.

## Live Demo
- **Netlify Live Link:** [https://inquisitive-lollipop-91ecf2.netlify.app](https://inquisitive-lollipop-91ecf2.netlify.app)

## Features
- **Hero Section:** Full-viewport banner featuring high-resolution vehicle imagery, prominent headline, call-to-action buttons, and smooth scroll indicator.
- **Featured Models Section:** Clean CSS Grid layout showcasing the 4 flagship electric vehicles (Model S, Model 3, Model X, Model Y) with performance specs (Range, 0-60 mph, Top Speed) and action buttons.
- **Navigation & Footer:** Fixed frosted navigation bar with smooth anchor links, paired with a clean footer bar containing legal and site navigation links.
- **Responsive Design:** Basic media query for mobile screens (Bonus).

## Technologies Used
- HTML5 (Semantic structure)
- CSS3 (Flexbox, CSS Grid, Transitions, Media Queries)

## How to Run Locally
1. Clone or download this repository.
2. Open `index.html` directly in any modern web browser.
